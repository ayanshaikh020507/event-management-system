# Event Management System
Full-stack MERN app to create, view, update, delete and search events.

**Stack:** React, Node.js, Express, MongoDB (Mongoose)

## Run locally
Needs Node.js and MongoDB running on your machine.

```bash
# backend (port 3001)
cd server
npm install
npm start

# frontend (port 3000)
cd event-management
npm install
npm start
```
Demo login: `admin` / `admin123` (demo only, not real authentication).
